# ローグライク・ローテーションバトル

前列は戦い、中列は支え、後列は休む。
ターンの終わりに「回す」か「維持する」かを選ぶ、ブラウザで遊べる戦術バトルです。

## 遊び方

- スマホ・パソコンのブラウザで開くだけで遊べます（インストール不要）。
- スマホではホーム画面に追加すると、全画面のアプリとして遊べます。
- はじめての方は、タイトル画面の「チュートリアル」から。

- 画面上の「×2」ボタンで、戦闘の演出が2倍速になります（もう一度押すと元に戻り、設定は保存されます）。
- 10月だけ、タイトル画面の「見た目」でハロウィン版（団員と敵の絵・名前、夜の配色）を選べます。戦闘の中身は変わりません。
## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（HTML・CSS・JavaScript・効果音／BGMの合成まで1ファイル） |
| `manifest.webmanifest` | ホーム画面に追加したときのアプリ設定 |
| `sw.js` | 一度開けばオフラインでも遊べるようにする仕組み |
| `icon-*.png` ほか | アイコン |

外部ライブラリは使っていません（フォントのみ Google Fonts から読み込み）。

## 調整用シミュレーター

`tools/sim.mjs` は、ゲーム本体の `JOBS`・`ENEMIES`・`RULES` をそのまま読み込んで戦わせる自動対戦シミュレーターです。

```
node tools/sim.mjs
```

戦闘ごとに「一度も回さない」戦い方の勝率（いろいろな隊列で試した割合）と、「毎ターン回す」勝率、初期隊列で勝てる回し方の割合、最良の回し方を出します。調整の基準は「一度も回さない」勝率が20%未満であることです。

`tools/runsim.mjs` は「騎士団の30年」（1ラン）を丸ごと自動で遊び、クリア率を出します。戦い方は「回さない」「回す判断あり（簡単なルール）」「先読みの名人（10手先まで全部試す）」の3種類です。

```
node tools/runsim.mjs 200
node tools/runsim.mjs 200 '{"sortie":8}'   # RUN の値を一時的に上書きして試す
```

あわせて「戦闘を常に選ぶ」「休息を優先」「報酬はいつも継承」など、選び方ごとのクリア率も出します。どれか1つだけが極端に高い（または0%に近い）ときは、その選び方しかない状態になっているので調整が必要です。

## ローグライク要素（Into the Breach 由来）

- **騎士団の選択と解禁**：本番を一度終えると、開始時に騎士団を選べる。実績か勲章で新しい騎士団が解禁される。
- **第N代の記録**：本番の1回を「第N代」として数え、負けても年代記は次の代へ続く。
- **語り継がれる者**：本番の終わりに残った団員・引退した団員から1人を次の代へ連れていける（能力はそのまま、28歳に戻り、同じ職業の初期団員と入れ替わる）。
- **章の終わりの店**：戦闘の★が名声になり、地点3・6の砦のあとで手当て・装備・入団者・稽古を買える。
- **地方を選ぶ**：中盤・終盤の入口で地方（獣の森・毒の沼地・鉄の砦）を選び、その章の変異種の種類が決まる。

値は `index.html` の `ROGUE`（と `SQUADS`）にまとまっている。`tools/rogue.mjs` で、各要素がクリア率をどれだけ動かすかを測れる。

```
node tools/rogue.mjs 200
```

`tools/runsim.mjs` はゲームと同じ設定（店・地方選びあり）で測る。従来の測り方（要素なし）と比べるときは `tools/rogue.mjs` を使う。
