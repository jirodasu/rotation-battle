# ローテーションバトル

前列は戦い、中列は支え、後列は休む。
ターンの終わりに「回す」か「維持する」かを選ぶ、ブラウザで遊べる戦術バトルです。

## 遊び方

- スマホ・パソコンのブラウザで開くだけで遊べます（インストール不要）。
- スマホではホーム画面に追加すると、全画面のアプリとして遊べます。
- はじめての方は、タイトル画面の「チュートリアル」から。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（HTML・CSS・JavaScript・効果音／BGMの合成まで1ファイル） |
| `manifest.webmanifest` | ホーム画面に追加したときのアプリ設定 |
| `sw.js` | 一度開けばオフラインでも遊べるようにする仕組み |
| `icon-*.png` ほか | アイコン |

外部ライブラリは使っていません（フォントのみ Google Fonts から読み込み）。

## 調整用シミュレーター

`tools/sim.mjs` は、ゲーム本体の `JOBS`・`ENEMIES`・`RULES` をそのまま読み込んで戦わせる自動対戦シミュレーターです。

```
node tools/sim.mjs
```

戦闘ごとに「一度も回さない」戦い方の勝率（いろいろな隊列で試した割合）と、「毎ターン回す」勝率、初期隊列で勝てる回し方の割合、最良の回し方を出します。調整の基準は「一度も回さない」勝率が20%未満であることです。

`tools/runsim.mjs` は「騎士団の30年」（1ラン）を丸ごと自動で遊び、クリア率を出します。戦い方は「回さない」「回す判断あり（簡単なルール）」「先読みの名人（10手先まで全部試す）」の3種類です。

```
node tools/runsim.mjs 200
```
