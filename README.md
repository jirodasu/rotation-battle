# ローテーションバトル

前列は戦い、中列は支え、後列は休む。
ターンの終わりに「回す」か「維持する」かを選ぶ、ブラウザで遊べる戦術バトルです。

## 遊び方

- スマホ・パソコンのブラウザで開くだけで遊べます（インストール不要）。
- スマホではホーム画面に追加すると、全画面のアプリとして遊べます。
- はじめての方は、タイトル画面の「チュートリアル」から。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（HTML・CSS・JavaScript・効果音／BGMの合成まで1ファイル） |
| `manifest.webmanifest` | ホーム画面に追加したときのアプリ設定 |
| `sw.js` | 一度開けばオフラインでも遊べるようにする仕組み |
| `icon-*.png` ほか | アイコン |

外部ライブラリは使っていません（フォントのみ Google Fonts から読み込み）。
